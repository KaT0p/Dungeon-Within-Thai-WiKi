# Character images

เก็บรูปตัวละครที่แสดงบนเว็บไซต์ไว้ในโฟลเดอร์ย่อยตามประเภท:

- `dark-lords/` — จอมมาร
- `monsters/` — มอนสเตอร์
- `heroes/` — ฮีโร่
- `originals/` — ไฟล์ต้นฉบับสำหรับเก็บรักษา ไม่ควรเรียกใช้บนหน้าเว็บโดยตรง

## การตั้งชื่อ

- ใช้ชื่อภาษาอังกฤษตัวเล็กแบบ `kebab-case`
- รูปหน้ารวมใช้คำต่อท้าย `-thumbnail`
- รูปหน้ารายละเอียดใช้ชื่อปกติ

ตัวอย่าง:

```text
monsters/wendigo-thumbnail.webp
monsters/wendigo.webp
```

ก่อนเพิ่มรูป ให้บันทึกแหล่งที่มาและสิทธิ์การใช้งานใน `docs/IMAGE_CREDITS.md`
