## สิ่งที่ยังไม่สรุปหลัง Phase 2.3c

- บทบาทของมอนสเตอร์แต่ละตัว
- คำอธิบายและสูตรของ Base Attack, Innate Trait, Main Part และ Sub Parts สำหรับตัวที่ยังไม่มีหน้ารายละเอียด
- ค่าสถานะเต็มและ Dominance Cost
- Immunity, Resistance และ Vulnerability
- ซินเนอร์จีกับ Dark Lord, Facility หรือมอนสเตอร์อื่น
- Tier list หรือคำแนะนำ Build

## ผลลัพธ์ Phase 2.3b–2.3c

Phase 2.3b ทำหน้าต้นแบบ 3 ตัวที่มีกลไกและระดับต่างกัน:

1. **Wendigo (Tier 3, Beast)** — ตัวอย่างแนวหน้าที่มีการป้องกันและฟื้นฟู
2. **Arachne (Tier 6, Elemental)** — ตัวอย่างกลไก Web และ Restrained
3. **Transcendent (Tier 9, Elemental)** — ตัวอย่างมอนสเตอร์ Fusion ระดับสูงและ Psychic synergy

ตัวเลือกทั้งสามเป็นข้อเสนอเพื่อให้ Schema ครอบคลุมหลายรูปแบบ ไม่ใช่ Tier ranking

Phase 2.3c แปลชื่อสกิลและชิ้นส่วนของมอนสเตอร์ Tier 1–3 ครบ 26 ตัว รวม 130 ชื่อ และเพิ่มหน้าค้นหาบนเว็บไซต์ รายละเอียดอยู่ใน [MONSTER_SKILL_TRANSLATIONS.md](./MONSTER_SKILL_TRANSLATIONS.md)
