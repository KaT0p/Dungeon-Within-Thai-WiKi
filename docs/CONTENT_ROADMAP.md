# Dungeon Within Thailand Wiki — Content Roadmap

เอกสารนี้เป็นรายการงานสำหรับสร้าง Wiki ภาษาไทยที่มีข้อมูลใช้งานได้จริง โดยให้ความสำคัญกับความถูกต้อง แหล่งอ้างอิง และเวอร์ชันเกมก่อนงานออกแบบเว็บไซต์

## เป้าหมายของโปรเจกต์

- เป็นศูนย์รวมข้อมูลเกม Dungeon Within ภาษาไทย
- ช่วยผู้เล่นค้นข้อมูลเฉพาะได้รวดเร็ว ไม่ใช่เพียงบทความแนะนำทั่วไป
- แสดงข้อมูลเป็นตาราง การ์ด ตัวกรอง และหน้ารายละเอียดที่เปรียบเทียบกันได้
- ระบุเวอร์ชันเกม วันที่ตรวจสอบ และแหล่งอ้างอิงในทุกหน้าที่มีข้อมูลเชิงตัวเลข
- รักษาชื่อภาษาอังกฤษไว้ควบคู่กับคำแปลไทย เพื่อให้ค้นข้อมูลจากแหล่งสากลต่อได้

## หลักการก่อนเริ่ม

- [ ] ห้ามแต่งค่าสถานะ สกิล หรือรายละเอียดที่ยังตรวจสอบไม่ได้
- [ ] ข้อมูลที่ไม่แน่ใจต้องติดป้าย `ต้องตรวจสอบ`
- [ ] แยกข้อเท็จจริงออกจากความคิดเห็นหรือคำแนะนำของผู้เขียน
- [ ] Tier list และ Build ต้องระบุเวอร์ชันเกมเสมอ
- [ ] ตรวจสอบสิทธิ์การใช้ข้อความและภาพจากแหล่งต้นทางก่อนนำมาเผยแพร่
- [ ] ใช้ภาพจากเกมหรือ Wiki ต้นทางเฉพาะเมื่อมีสิทธิ์และให้เครดิตถูกต้อง
- [ ] ระบุว่าเว็บไซต์เป็นโปรเจกต์แฟนเมดและไม่เกี่ยวข้องกับ GameCoaster

## Phase 1 — กำหนดมาตรฐานข้อมูล

### 1.1 แหล่งข้อมูล

- [x] บันทึกลิงก์ Wiki ภาษาอังกฤษ
- [x] บันทึกลิงก์หน้าร้านอย่างเป็นทางการ
- [x] รวบรวม Patch Notes และ Developer Notes
- [x] กำหนดวิธีรวบรวมข้อมูลที่ตรวจสอบจากภายในเกม
- [x] กำหนดลำดับความน่าเชื่อถือของแหล่งข้อมูล
- [x] สร้างรายการข้อมูลที่ Wiki อังกฤษยังขาดหรืออาจล้าสมัย

รายละเอียดผลลัพธ์: [SOURCES.md](./SOURCES.md)

ลำดับแหล่งข้อมูลที่แนะนำ:

1. ข้อมูลที่แสดงในเกมเวอร์ชันปัจจุบัน
2. Patch Notes หรือประกาศจากผู้พัฒนา
3. Wiki ต้นทางที่มีแหล่งอ้างอิง
4. การทดสอบซ้ำโดยผู้เล่นหลายคน
5. ความเห็นจากชุมชน ซึ่งต้องระบุว่าเป็นความคิดเห็น

### 1.2 มาตรฐานคำแปล

- [x] สร้างพจนานุกรมศัพท์อังกฤษ–ไทย
- [x] กำหนดคำแปลของชื่อระบบ เช่น Skill, Trait, Facility, Room และ Trap
- [x] กำหนดว่าชื่อเฉพาะใดต้องคงภาษาอังกฤษ
- [x] กำหนดรูปแบบการเขียนตัวเลข เปอร์เซ็นต์ ระยะเวลา และระดับ
- [x] กำหนดรูปแบบชื่อหน้าและ URL เบื้องต้น

รายละเอียดผลลัพธ์: [GLOSSARY.md](./GLOSSARY.md)

ตัวอย่างรูปแบบ:

| English | คำไทยที่ใช้ | หมายเหตุ |
|---|---|---|
| Dark Lord | จอมมาร | แสดงชื่ออังกฤษของตัวละครตามเกม |
| Monster | มอนสเตอร์ | ใช้คำทับศัพท์เพื่อให้ค้นหาง่าย |
| Room | ห้อง | ระบุประเภทห้องเพิ่มเติมเมื่อจำเป็น |
| Trap | กับดัก | ใช้ชื่ออังกฤษควบคู่ในหน้ารายละเอียด |
| Synergy | ซินเนอร์จี / การเสริมพลังร่วมกัน | เลือกคำหลักหนึ่งคำหลังตรวจ UI เกม |
| Run | รอบการเล่น | หลีกเลี่ยงการแปลหลายแบบ |

### 1.3 โครงสร้างข้อมูลร่วม

- [x] ทุกข้อมูลมี `ชื่ออังกฤษ`
- [x] ทุกข้อมูลมี `ชื่อไทย` หรือคำอธิบายไทย
- [x] ทุกข้อมูลมี `หมวดหมู่`
- [x] ทุกข้อมูลมี `เวอร์ชันที่ตรวจสอบ`
- [x] ทุกข้อมูลมี `วันที่อัปเดต`
- [x] ทุกข้อมูลมี `แหล่งอ้างอิง`
- [x] ทุกข้อมูลมีสถานะ `ตรวจสอบแล้ว` หรือ `ต้องตรวจสอบ`
- [x] ข้อมูลเชิงกลยุทธ์แยกจากข้อมูลพื้นฐานอย่างชัดเจน

รายละเอียดผลลัพธ์: [DATA_SCHEMA.md](./DATA_SCHEMA.md)

ผลลัพธ์ของ Phase 1:

- ไฟล์พจนานุกรมคำศัพท์ฉบับแรก
- รายการแหล่งข้อมูลที่เชื่อถือได้
- รูปแบบข้อมูลมาตรฐานหนึ่งชุด

## Phase 3 — สร้างฐานข้อมูลขั้นต่ำที่ใช้งานได้จริง (MVP)

ไม่ต้องรอให้ข้อมูลครบทั้งเกม เลือกข้อมูลที่ผู้เล่นใช้บ่อยที่สุดก่อน

### 3.1 เนื้อหา MVP

- [ ] คู่มือเริ่มต้นที่อ้างอิงระบบจริงในเกม
- [ ] หน้ารวมจอมมารทั้งหมด
- [ ] หน้ารายละเอียดจอมมารอย่างน้อย 3 ตัว
- [ ] หน้ารวมมอนสเตอร์พร้อมค้นหาและกรอง
- [ ] หน้ารายละเอียดมอนสเตอร์อย่างน้อย 10 ตัว
- [ ] หน้ารวมห้องและกับดักพร้อมค้นหาและกรอง
- [ ] หน้ารายละเอียดห้องหรือกับดักอย่างน้อย 10 รายการ
- [ ] พจนานุกรมศัพท์อังกฤษ–ไทย
- [ ] หน้ารวม Patch Notes
- [ ] หน้าแหล่งอ้างอิงและเครดิต

### 3.2 ข้อมูลที่ควรกรองได้

- [ ] ประเภทข้อมูล
- [ ] เผ่าหรือแท็ก
- [ ] ระดับความหายาก
- [ ] บทบาท
- [ ] ธาตุ หากเกมมีระบบธาตุ
- [ ] เวอร์ชันที่เพิ่มหรือแก้ไข
- [ ] สถานะการตรวจสอบข้อมูล

### 3.3 ข้อมูลที่ควรเปรียบเทียบได้

- [ ] ค่าสถานะของมอนสเตอร์
- [ ] เอฟเฟกต์และค่าตามระดับของห้อง
- [ ] ผลของไอเทม
- [ ] จุดเด่นและข้อจำกัดของจอมมาร

ผลลัพธ์ของ Phase 3:

- ข้อมูลจริงเพียงพอสำหรับผู้เล่นค้นหาและใช้อ้างอิง
- มีอย่างน้อยหนึ่งหน้าที่แสดงตารางและตัวกรอง
- มีหน้ารายละเอียดที่ใช้รูปแบบเดียวกันทุกหมวด

- [ ] ค้นจากคำอธิบายและแท็ก
- [ ] แยกผลลัพธ์ตามประเภท
- [ ] แสดงคำที่ตรงกับการค้นหา
- [ ] รองรับกรณีพิมพ์ผิดเล็กน้อยในอนาคต

ผลลัพธ์ของ Phase 4:

- เว็บไซต์ไม่ได้เป็นเพียงข้อความ แต่เป็นเครื่องมือค้นและสำรวจข้อมูลเกม
- หน้าแรกเชื่อมไปยังข้อมูลจริงทั้งหมด
- ผู้เล่นค้นข้อมูลสำคัญได้ภายในไม่กี่ขั้นตอน

- [ ] วิธีออกแบบลำดับห้องและกับดัก

- [ ] ข้อผิดพลาดที่พบบ่อย
- [ ] FAQ จากคำถามของชุมชนไทย

- [ ] บันทึกผู้เขียน ผู้ทดสอบ และเวอร์ชันของทุก Build

## Definition of Done — ก่อนเรียกว่าเว็บรุ่นแรกพร้อมใช้

- [ ] ไม่มีค่าสถานะหรือรายละเอียดที่แต่งขึ้น
- [ ] ข้อมูลสำคัญทุกหน้ามีแหล่งอ้างอิง
- [ ] ข้อมูลทุกหน้าระบุเวอร์ชันและวันที่ตรวจสอบ
- [ ] มีจอมมาร มอนสเตอร์ และห้อง/กับดักที่ใช้เป็นข้อมูลจริง
- [ ] การค้นหาจากชื่อไทยและอังกฤษทำงานได้
- [ ] ตัวกรองบนหน้ารวมใช้งานได้ทั้งคอมพิวเตอร์และมือถือ
- [ ] ผู้เล่นสามารถหาคำตอบที่เฉพาะเจาะจงได้ ไม่ใช่เพียงอ่านข้อความทั่วไป
